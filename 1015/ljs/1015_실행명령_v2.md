# 10/15 실행 명령 v2 (P3 = .60 / DESKTOP-19T7OTG / MAC 40:d1:33:cd:46:69)

모든 명령은 **Windows PowerShell(관리자)** 에서 실행합니다. 결과는 `1015/ljs/`에 올립니다.
어제 버전에서 바뀐 점: B 삭제(1013 자료로 답이 나옴), C 보강(밀리초 이벤트, ping 3개, 패킷 캡처).

---

## 1. P3 — 커널 잠금 증거 (반드시 `wsl --shutdown` 전에 실행)

WSL 안에서 `ip`, `ifconfig`, `sudo`는 실행하지 마세요. 실행할 때마다 멈춘 프로세스가 하나씩 쌓입니다.

```powershell
Select-String -Path C:\Users\admin\blocked_full.txt -Pattern 'kworker|netvsc|vmbus|rndis|unregister_netdevice|netdev_run_todo|wait_for_completion|synchronize' -Context 3,25 | Out-File C:\Users\admin\blocked_holders.txt
Compress-Archive C:\Users\admin\blocked_full.txt C:\Users\admin\blocked_full.zip -Force
Select-String -Path C:\Users\admin\blocked_full.txt -Pattern 'task:' | % { ($_.Line -split 'task:')[1] -replace ' stack:.*','' } | Group-Object | Sort-Object Count -Descending | Format-Table Count,Name -AutoSize | Out-File C:\Users\admin\blocked_count.txt
```
재부팅하지 않았다면 아래도 실행합니다 (멈추면 Ctrl+C 후 건너뜀).
```powershell
wsl -d Ubuntu-22.04 -u root -e sh -c "dmesg | grep -iE 'unregister_netdevice|netvsc|vmbus|eth2' | tail -100" > C:\Users\admin\dmesg_net.txt
```
**올릴 것:** `blocked_holders.txt`, `blocked_full.zip`, `blocked_count.txt`, `dmesg_net.txt`

## 3. P3 — 로밍 직후 15초 동안 실제로 끊기는지 확인 (업데이트 후 장비 운행 중)

**목적:** 인증 성공(11005) 직후부터 통신이 끊기는지(→ AP/무선망 문제), 4003·8000 시점부터 끊기는지(→ Windows/드라이버 문제) 구분합니다.

**3-1. ping 3개를 각각 별도 PowerShell 창에서 실행해 두기**
```powershell
New-Item -ItemType Directory -Force C:\Temp | Out-Null
ping.exe -t 10.249.138.1 | % { "{0:HH:mm:ss.fff} {1}" -f (Get-Date),$_ } | Out-File C:\Temp\ping-gw.log
```
```powershell
ping.exe -t 10.244.201.165 | % { "{0:HH:mm:ss.fff} {1}" -f (Get-Date),$_ } | Out-File C:\Temp\ping-frs.log
```
```powershell
wsl -d Ubuntu-22.04 -u root -e sh -c "ping -D 10.249.138.1 > /mnt/c/Temp/ping-wsl.log"
```

**3-2. 패킷 캡처 (ARP, ICMP, DHCP만, 순환 기록)**
```powershell
pktmon filter remove
pktmon filter add -d ARP
pktmon filter add -t ICMP
pktmon filter add -t UDP -p 67
pktmon start --capture --comp nics --file-name C:\Temp\roam.etl --file-size 256 --log-mode circular
```

**3-3. 4003이 1~2번 발생할 때까지 운행** (발생 여부 확인)
```powershell
Get-WinEvent -FilterHashtable @{LogName='System';StartTime=(Get-Date).Date} | ? Id -eq 4003 | select TimeCreated
```

**3-4. 4003 발생 후 수집**
```powershell
pktmon stop
pktmon etl2pcapng C:\Temp\roam.etl --out C:\Temp\roam.pcapng
$s=(Get-Date).Date
Get-WinEvent -FilterHashtable @{LogName='System';StartTime=$s} | ? { $_.ProviderName -match 'Netwtw|NDIS|Tcpip|Dhcp|Kernel-PnP|WLAN' } | select @{n='T';e={$_.TimeCreated.ToString('HH:mm:ss.fff')}},ProviderName,Id,Message | Export-Csv C:\Temp\network-system.csv -NoTypeInformation -Encoding UTF8
Get-WinEvent -FilterHashtable @{LogName='Microsoft-Windows-WLAN-AutoConfig/Operational';StartTime=$s} | select @{n='T';e={$_.TimeCreated.ToString('HH:mm:ss.fff')}},Id,Message | Export-Csv C:\Temp\wlan-op.csv -NoTypeInformation -Encoding UTF8
netsh wlan show wlanreport
```
ping 창 3개는 Ctrl+C로 종료합니다.

**올릴 것:** `ping-gw.log`, `ping-frs.log`, `ping-wsl.log`, `roam.pcapng`, `network-system.csv`, `wlan-op.csv`, `C:\ProgramData\Microsoft\Windows\WlanReport\wlan-report-latest.html`
(이번 단계에서는 설정을 바꾸지 않습니다. PMK 캐시와 로밍 적극성도 그대로 둡니다.)
