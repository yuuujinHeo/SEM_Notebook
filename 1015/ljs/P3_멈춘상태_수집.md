# P3(.60) 멈춘 상태 증거 수집 — 재시작 전에만 가능 (기본 폴더: C:\Users\admin\Desktop\ALGN)

**재시작, `wsl --shutdown`, `wsl --terminate` 금지.**
WSL 안에서 `ip`, `ifconfig`, `hostname`, `sudo`, `nmcli`, `/sys/class/net/...` 사용 금지 (실행할 때마다 멈춘 프로세스가 하나씩 쌓임).
모든 명령은 **Windows PowerShell(관리자)** 에서 실행합니다.

## 0. 기본 폴더 지정 (PowerShell 창을 새로 열 때마다 먼저 실행)
```powershell
$A='C:\Users\admin\Desktop\ALGN'; $o="$A\frozen"
New-Item -ItemType Directory -Force $o | Out-Null
```

## 1. 리눅스 커널 상태 (재시작하면 사라짐)
`frozen.sh`를 `C:\Users\admin\Desktop\ALGN\frozen.sh`로 저장한 뒤 실행합니다.
```powershell
wsl -d Ubuntu-22.04 -u root -e sh -c "tr -d '\r' < /mnt/c/Users/admin/Desktop/ALGN/frozen.sh | sh"
Get-Content $o\05_sysrq_t.txt -TotalCount 3
```
[0]~[7]과 "완료"가 출력되면 정상입니다. 특정 번호에서 1분 넘게 멈추면 Ctrl+C를 누르고, 몇 번에서 멈췄는지 알려 주세요.

## 2. Windows 쪽 현재 상태
```powershell
hnsdiag list all                          > $o\win_hns.txt 2>&1
Get-NetAdapter -IncludeHidden | fl *      > $o\win_adapters.txt
Get-NetIPAddress | ft -AutoSize           > $o\win_ip.txt
Get-NetRoute | ft -AutoSize               > $o\win_route.txt
Get-NetIPInterface | ft -AutoSize         > $o\win_ipif.txt
Get-NetFirewallHyperVVMSetting -ErrorAction SilentlyContinue | fl * > $o\win_hv_fw.txt
```

## 3. Windows 이벤트 (10/14 08:30~08:45)
```powershell
$s=[datetime]'2026-10-14 08:30'; $e=[datetime]'2026-10-14 08:45'
'Microsoft-Windows-Hyper-V-Compute-Operational','Microsoft-Windows-Host-Network-Service-Admin','Microsoft-Windows-Host-Network-Service-Operational','System' | ForEach-Object {
  Get-WinEvent -FilterHashtable @{LogName=$_;StartTime=$s;EndTime=$e} -ErrorAction SilentlyContinue
} | Select-Object @{n='T';e={$_.TimeCreated.ToString('HH:mm:ss.fff')}},LogName,ProviderName,Id,Message | Export-Csv $o\win_events_0838.csv -NoTypeInformation -Encoding UTF8
(Import-Csv $o\win_events_0838.csv).Count
```
